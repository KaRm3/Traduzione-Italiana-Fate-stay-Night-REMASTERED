# Traduzione-Italiana-Fate-stay-Night-REMASTERED
Traduzione italiana di Fate/stay Night REMASTERED , basata sulla patch storica di Riffour Translations.
# Installazione
1. Premi Win+R, incolla: %LOCALAPPDATA%\typemoon\fsn2
2. Estrai il contenuto di questo archivio dentro quella cartella, sovrascrivendo i file. 
### si raccomanda vivamente di installare l'ultima release disponibile
https://github.com/KaRm3/Traduzione-Italiana-Fate-stay-Night-REMASTERED/releases/tag/Transl1.1
## Differenze con la patch originale
La patch da me creata adotta alcune differenze da quella di Riffour, principalmente nella terminologia,
ho fatto in modo di renderla il piú fedele possibile alle radici giapponesi, spero vi piaccia.

PS : La patch NON contiene testo tradotto con AI.
