# Traduzione-Italiana-Fate-stay-Night-REMASTERED
Traduzione italiana di Fate/stay Night REMASTERED , basata sulla patch storica di Riffour Translations
Per installare o ripristinare la traduzione:
1. Premi Win+R, incolla: %LOCALAPPDATA%\typemoon\fsn2
2. Estrai il contenuto di questo archivio dentro quella cartella, sovrascrivendo i file.
